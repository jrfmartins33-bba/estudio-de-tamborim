# Estúdio de Tamborim

Projeto migrado do Lovable para desenvolvimento direto com GitHub, Codex/Claude Code, Vercel e Supabase.

- Não depender de Lovable para build, deploy ou alterações de código.
- Preservar o Supabase existente enquanto a migração é validada.
- Interface e documentação em português do Brasil.
- Usar “acentuação”, nunca “acento”, para o atributo musical.
- Não inventar informação musical: itens não confirmados devem permanecer como hipótese ou a validar.
